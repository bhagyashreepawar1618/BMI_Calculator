## ✨ Features

- 📏 Input height and weight
- 🧮 Calculate BMI instantly
- 📊 Display BMI result
- 🏷 Show BMI category (Underweight / Normal / Overweight / Obese)
- ❌ Input validation
- 📱 Simple and responsive UI

---

## ⚙ How It Works

1. User enters height and weight.
2. Clicks the "Calculate" button.
3. JavaScript calculates BMI using the formula:

   **BMI = weight (kg) / (height (m)²)**

4. Result is displayed dynamically on the page.
5. BMI category is shown based on the calculated value.
